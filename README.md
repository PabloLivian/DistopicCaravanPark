# Procedural Caravans: The Stacks

Diario de producción de un parque de caravanas apiladas, procedural en Houdini 22, inspirado en "The Stacks" de *Ready Player One*.

Se ve online con GitHub Pages: abre `index.html`.

Esta carpeta se genera desde el proyecto con `python -I docs/publicar_avances.py --web web`. No la edites a mano.
